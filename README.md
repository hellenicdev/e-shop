# Web Services Shop

[![Live demo](https://img.shields.io/badge/demo-live-19336e?style=flat-square)](https://hellenicdev.eu/e-shop/) [![License: MIT](https://img.shields.io/badge/license-MIT-blue?style=flat-square)](LICENSE)

A simple pricing page for HellenicDev website-build packages.

**Live site:** <https://hellenicdev.eu/e-shop/>

## Features

- Three packages: Simple (€5), Advanced (€10) and Extreme (€15)
- One-click order by email for each package
- Responsive, dark-themed layout

## Run locally

No build step. Open `index.html` or serve the folder with any static server:

```sh
git clone https://github.com/hellenicdev/e-shop.git
cd e-shop
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
